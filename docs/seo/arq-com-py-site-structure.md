# arq.com.py — Page & SEO Structure

**Positioning:** premium architecture project-acquisition brand. NOT an architecture practice — it generates design demand,
qualifies leads, and assembles the right expert team per project (architect/engineer partners). Cinematic desktop, very fast elegant mobile. Spanish only, Gran Asunción primary.

**Brand boundary:** arq = design intent (planos, diseño, renders, carpeta municipal, regularización).
Execution keywords (construcción, obra, llave en mano) belong to obra.com.py. Every arq lead gets the
"¿y quién te la construye?" follow-up → obra pipeline. That handoff is the whole point of owning both.

**URL rule:** short slugs, max 2 levels, Ads display-path friendly.

**Conventions:** WhatsApp-first (+595 992 279 599), no prices, PYG only, AI-generated architectural
imagery with strict "doesn't look AI" rules, no named architects stage 1.

~15 pages.

## Page template

1. H1: primary keyword + "en Paraguay" / "Asunción"
2. Cinematic visual block (AI renders, PY context: ladrillo visto, hormigón, vegetación)
3. Qué incluye (for /planos/: anteproyecto, plantas, fachadas, cortes, planilla, documentación para municipalidad)
4. Proceso en pasos + plazos indicativos
5. FAQ + schema: qué necesito para empezar, plazos, qué municipios, diferencia anteproyecto/proyecto
6. WhatsApp CTA + /cotizar/; soft link "¿ya querés construir? → obra.com.py"

## SEO notes

- Head terms: "arquitecto", "planos de casas", "diseño de casas". Home + two anchors carry them.
- /estilos/ cluster is the traffic engine — "casas minimalistas / modernas / fachadas" have browse volume; convert with "pedí tu anteproyecto" CTA and retarget.
- /regularizacion/ and /carpeta/ are the money pages competitors ignore — urgent, blocked users, fast WhatsApp conversion.
- Cross-links: /interiores/ → carpinteria.com.py; every service page footer → obra.com.py ("del plano a la obra"); /renders/ → desarrollador(es).com.py B2B angle. One contextual link per page.
- Schema: ProfessionalService + Service; FAQPage.
- Imagery rules (strict anti-AI-look): real-world lighting, PY materials (ladrillo visto, hormigón), no impossible geometry, no text in images, consistent style Element in Higgsfield across the site.
